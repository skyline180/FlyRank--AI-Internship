# FlyRank Backend Track - Week 3 Database CRUD API

A RESTful API built with Python and FastAPI, persisting data to a local SQLite database.

**Author**: Md. Shahat Akash
**Contact**: shahat.akash@gmail.com

## Installation & Running the Server

The database file (`tasks.db`) will be created automatically the first time the server runs[cite: 2].

```bash
pip install fastapi uvicorn && uvicorn main:app --reload
```
